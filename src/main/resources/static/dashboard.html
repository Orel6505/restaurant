Getting Started

  1. Your JWT token is stored in browser's localStorage
  2. Visit API Documentation to explore all endpoints
  3. All API requests automatically include your authentication token
  4. Your access level is determined by your assigned roles (ADMIN, MANAGER, or USER)
  5. Logout to clear your authentication credentials
